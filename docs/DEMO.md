# SLOT demonstration

## A reproducible tour

Open /demo → Explore as a client → select a session → reserve → confirm demo payment → My sessions → reschedule or cancel → switch to coach → run the concurrency demo.

## What to say

Explain the user problem first, then one real interaction, then one design tradeoff. Show an error case and the current limit. Do not imply a model, paid service or production deployment is active when it is not.

## Capture rules

Record the actual current build. All studio people and bookings are fictional. Never show account credentials, environment files, private browser tabs or personal camera footage. If the presentation uses edited screenshots, label it **Narrated walkthrough using real application captures**, not a continuous live recording. Keep public narration and captions in English; the learning version is French.

## Public demo status

Deployment and video URLs are added only after successful publication. Local captures belong in `docs/screenshots/`. Video transcripts and captions should remain available independently of the player.

## Narrated videos

Open `/demo-video` and choose English or French. Press **Play video** to start the spoken explanation. The player starts unmuted and offers explicit mute/unmute, restart, download, captions and transcript controls.

The videos contain real interactions recorded from the application, edited with synthetic narration and embedded captions. See [capture method and voice credits](MEDIA.md). No ASL recognition or signed-video generation is claimed.
